# LangGraph 实验课维护约定

本模块承接用户要求新增的学习课程，后续同系列课程继续放在这里。保留原有 LangGraph 基础模块的七篇文章，不把新增实验混回基础目录。

- 标题使用知识点或工程问题，不添加作者、工具名或 `[codex]` 标记。
- 一课只引入一个核心机制；先交代问题，再解释机制与代码中的数据流。
- 代码直接完整展开在页面，包含导入、状态、节点、连线和入口；不要求下载或引用本机资料目录。
- 删除与本课机制无关的包装节点。不要为了满足行数省略必要分支、退出条件或边界说明。
- 说明如何保存、安装、运行以及观察输出。模拟模型与真实调用必须明确区分。
- 给一个有具体预期的修改练习；提示读者同步更新受影响的断言。
- 重编号时同步文件名、阅读顺序、显式下一篇链接、模块目录与 `_data/nav.yml`。
- 对页面代码做独立提取运行，核对输出；真实模型未运行时明确记录。遵守根目录的构建、引号和 Git 规则。
